GOLDENEYE 64

Minecraft Battle Royale Mod

A GoldenEye 007–inspired gun mod for Minecraft Java Edition. Eleven iconic weapons, ten agents, five villains, and a full battle royale match runner.

Get the mod Join our match

How to Install

1
Install Java 17
Download Adoptium Temurin 17
2
Install Minecraft 1.20.1
Open the Minecraft launcher and run version 1.20.1 once.
3
Install Fabric Loader
Download the Fabric Installer → pick MC 1.20.1 → install.
4
Drop the mod jars in mods/
Put goldeneye64-0.1.0.jar AND Fabric API in your Minecraft mods folder.
5
Launch Minecraft with the Fabric profile and pick the GoldenEye 64 world (or join our server).

Join the Match

Fire up Minecraft 1.20.1 (Fabric) and add this server:

Server IP:  [your server IP here]
Version:    1.20.1 Fabric

Update website/index.html with your real server IP before sharing.

Quick Commands

  • /br start 500 600 — start match (radius 500, shrinks over 10 min)
  • /br kit Bond — get an agent's loadout
  • /br agent 006 — set your codename
  • /br villains on — enable NPC villains for co-op mode
  • /br spawn jaws — summon a single villain (op only)
  • /br stop — end match
